APIs

Una API (Application Programming Interface) es un conjunto de reglas que permite que diferentes aplicaciones puedan comunicarse entre sí.

Las APIs permiten solicitar y recibir información utilizando diferentes formatos, como JSON.

Información sobre Sismos

Presiona el botón para consultar los datos de los sismos.

La información mostrada contiene diferentes características de los sismos:

  • Lugar: ubicación del sismo.
  • Magnitud: intensidad del movimiento.
  • Profundidad: profundidad aproximada.
  • Fecha: fecha en la que ocurrió.
